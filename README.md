# EarthPulse

EarthPulse is a web application for viewing and analyzing environmental conditions for a selected location. It brings together weather and air-quality data and presents them through a dashboard and interactive map.

## Purpose

Environmental data is often available through different sources, making it difficult to get a simple overview of the conditions at a particular location.

EarthPulse provides a single interface to view information such as:

- Temperature
- Humidity
- Wind speed
- Rainfall
- Air Quality Index (AQI)
- Environmental risk score
- Alerts

The application allows users to select a location and view its available environmental data on the dashboard and map.

## Features

- Location-based environmental data
- Interactive map
- Weather information
- Air quality information
- Environmental risk score
- Environmental alerts
- Dashboard for viewing the collected data

## Future Scope

EarthPulse can be extended to support:

- Historical environmental data and trend analysis
- More detailed air-quality information
- Additional environmental data sources
- More locations and regional comparisons
- Improved risk calculation using multiple environmental factors
- Weather and environmental forecasts
- Custom alerts based on user-defined thresholds
- Heatmaps for different environmental conditions
- Integration with additional datasets such as vegetation, flooding, and other environmental indicators
- Mobile application support
